Décider : comparer, puis choisir

Un programme d'ECE doit parfois choisir : conclure « compatibles » ou non selon un z-score, choisir le modèle qui convient aux mesures. Python compare deux valeurs, puis exécute un bloc de lignes ou un autre.

À retenir

  • Les comparaisons : < > <= (≤) >= (≥) == (égal) != (différent). Python répond True (vrai) ou False (faux).
  • = range une valeur, == compare deux valeurs : ne pas les confondre.
  • abs(x) donne la valeur absolue de x : abs(-0.05) vaut 0.05. C'est une fonction intégrée, comme round.
  • if (si), elif (sinon, si) et else (sinon) : chaque ligne se termine par deux-points :, et les lignes du bloc sont décalées de quatre espaces. Python teste les conditions dans l'ordre et n'exécute que le premier bloc dont la condition est vraie ; else sert quand aucune ne l'est.
  • Un décalage oublié provoque une IndentationError.
pH = 8.2
if pH < 7:
    print('solution acide')
elif pH == 7:
    print('solution neutre')
else:
    print('solution basique')     # affiche : solution basique

1.1 Vrai ou faux ?

Tapez ces comparaisons dans la console, puis répondez au quiz. Chaque réponse se vérifie dans la console.

Que répond Python ?

3 < 5

3 est bien plus petit que 5 : la comparaison est vraie, Python répond True.

10 != 10

!= signifie « différent de ». 10 n'est pas différent de 10 : False.

abs(-4.5)

La valeur absolue retire le signe moins : 4.5. Elle ne change pas la valeur elle-même.

abs(7.62 - 7.65) < 0.05

L'écart vaut −0,03, sa valeur absolue 0,03, qui est inférieure à 0,05 : True. Python calcule d'abord, puis compare.

5 = 5

Un seul = veut ranger une valeur, et on ne peut rien ranger dans le nombre 5 : SyntaxError. Pour comparer, il faut 5 == 5.

1.2 Compatible ou non ? Le z-score

Rappel de cours — Comparer à une valeur de référence

On compare une valeur expérimentale xexp, d'incertitude-type u(x), à une valeur de référence xréf à l'aide du z-score :

z = |xexp − xréf|u(x)

Critères retenus en terminale

z < 1 : l'écart est plus petit que l'incertitude, valeurs très compatibles.
1 ≤ z < 2 : l'écart est du même ordre que l'incertitude, valeurs compatibles.
z ≥ 2 : valeurs non compatibles.

Un titrage des ions chlorure donne Cexp = 2,05 × 10⁻² mol·L⁻¹, avec u(C) = 0,10 × 10⁻² mol·L⁻¹. La valeur de référence vaut Créf = 2,10 × 10⁻² mol·L⁻¹ (application de la fiche de cours).

  1. Compléter la ligne z = …….
  2. Compléter les deux conditions, d'après le rappel de cours, puis exécuter.
  3. Remplacer C_exp par 2,25 × 10⁻² mol·L⁻¹ et exécuter de nouveau.
  4. Remplacer C_exp par 2,32 × 10⁻² mol·L⁻¹ et exécuter de nouveau.
  1. Le numérateur du z-score est une valeur absolue : abs(C_exp - C_ref).
  2. La première condition teste le cas z < 1. Si elle est fausse, on sait déjà que z ≥ 1 : la deuxième n'a plus qu'à tester z < 2.
  3. Le cas z ≥ 2 n'a pas besoin de condition : c'est le else.
Voir une solution 
z = abs(C_exp - C_ref) / u_C
print('z =', round(z, 2))

if z < 1:
    print('valeurs très compatibles')
elif z < 2:
    print('valeurs compatibles')
else:
    print('valeurs non compatibles')

z = 0,5 : très compatibles. Avec 2,25 × 10⁻², z = 1,5 : compatibles. Avec 2,32 × 10⁻², z = 2,2 : non compatibles. Le elif n'est testé que si z < 1 est faux : inutile d'écrire z >= 1 and z < 2. L'ordre des conditions compte : si l'on testait z < 2 en premier, un z de 0,5 serait déclaré seulement « compatible ».

Répéter un calcul : la boucle for

Un tableau numpy calcule sur toutes les valeurs d'un coup. Mais il faut parfois traiter les mesures une à une : afficher une ligne par mesure, tester chacune, ou construire une liste au fur et à mesure. C'est le rôle de la boucle for.

À retenir

  • for x in liste: répète le bloc décalé de quatre espaces, une fois pour chaque élément ; x prend tour à tour chaque valeur de la liste.
  • range(4) donne les entiers 0, 1, 2, 3 : quatre valeurs, de 0 à 4 exclu. range(1, 4) donne 1, 2, 3.
  • for i in range(len(c)): parcourt les rangs d'une liste c ; c[i] est alors l'élément de rang i.
  • resultats = [] crée une liste vide ; resultats.append(x) ajoute x à la fin de la liste.
f = 440                   # fréquence du fondamental, en Hz
frequences = []           # liste vide
for n in range(1, 4):     # n vaut 1, puis 2, puis 3
    frequences.append(n * f)
print(frequences)         # hors de la boucle : affiche [440, 880, 1320]

2.1 Prédire ce que fait une boucle

Pour chaque programme, prédire l'affichage. Pour vérifier, copier le programme dans l'éditeur et l'exécuter.

Qu'affiche Python ?

for x in [1, 2, 3]:
print(x * 10)

Le bloc est exécuté trois fois, une fois par élément : trois print, donc trois lignes.

for i in range(4):
print(i)

range(4) commence à 0 et s'arrête avant 4 : quatre valeurs, 0, 1, 2 et 3.

for x in [1, 2]:
print(x)
print('fin')

print('fin') n'est pas décalé : il ne fait pas partie de la boucle. Il est exécuté une seule fois, après elle.

L = []
for n in range(1, 4):
L.append(n * 2)
print(L)

n vaut 1, 2 puis 3 ; à chaque tour, n * 2 est ajouté à la fin de la liste : [2, 4, 6].

2.3 Le pH d'un acide fort, mesure par mesure

TP6 — pH d'une solution aqueuse
Rappel de cours — pH d'une solution d'acide fort

Un acide fort réagit totalement avec l'eau : la concentration en ions oxonium à l'état final est égale à la concentration apportée en acide, C. Ainsi :

pH = −log(Cc0) avec c0 = 1 mol·L⁻¹

Au TP6, on a mesuré le pH de cinq solutions d'un acide fort. Le programme affiche, pour chaque solution, le pH mesuré et le pH théorique. On veut signaler les mesures qui s'écartent de plus de 0,05 unité pH de la théorie.

  1. Compléter la ligne pH_theo = ……, puis exécuter.
  2. Compléter la condition, pour qu'un message s'affiche quand l'écart dépasse 0,05. Quelles mesures faudrait-il vérifier ?
  1. Dans la boucle, la concentration de la solution de rang i est c[i].
  2. Le log du cours est np.log10, et il y a un signe moins devant.
  3. La condition compare la variable ecart à 0.05.
Voir une solution 
for i in range(len(c)):
    pH_theo = -np.log10(c[i])
    ecart = abs(pH[i] - pH_theo)
    print('C =', c[i], 'mol/L   pH mesuré :', pH[i], '  pH théorique :', round(pH_theo, 2))
    if ecart > 0.05:
        print('   à vérifier : écart de', round(ecart, 2))

Deux mesures s'écartent de plus de 0,05 : à 0,010 mol·L⁻¹ (écart 0,08) et à 0,005 mol·L⁻¹ (écart 0,05, un peu plus). range(len(c)) donne les rangs 0 à 4 : on lit ainsi c[i] et pH[i], deux valeurs qui vont ensemble.

Découper une série, tirer au hasard

Deux derniers outils. Une tranche extrait une partie d'une série de mesures sans la recopier. Les tirages au hasard de numpy simulent des mesures : c'est le principe de la méthode de Monte-Carlo, présente dans plusieurs sujets d'ECE.

À retenir — les tranches

  • x[:5] : les 5 premiers éléments, de rang 0 à 4. x[5:] : tous les éléments à partir du rang 5.
  • x[2:4] : les éléments de rang 2 et 3. Comme pour range, le rang de fin est exclu.
  • x[-1] : le dernier élément.
  • Une tranche d'une liste est une liste ; une tranche d'un tableau numpy est un tableau.

3.1 Le pH de l'eau du robinet

Un groupe a mesuré vingt fois le pH de l'eau du robinet au pH-mètre. Prédire ce que vaut chaque expression, puis vérifier dans l'éditeur, en changeant le contenu du print.

Que vaut…

mesures[:3]

Les trois premiers éléments, de rang 0, 1 et 2 : le rang 3 est exclu.

mesures[2:4]

Les rangs 2 et 3, soit les 3ᵉ et 4ᵉ mesures. Python écrit 7,60 sous la forme 7.6 : le zéro final ne change pas la valeur.

mesures[-1]

Le rang −1 désigne le dernier élément : 7,61. C'est un nombre, pas une liste : un seul élément, sans crochets.

mesures[18:]

Vingt mesures, de rang 0 à 19 : à partir du rang 18, il reste les deux dernières.

len(mesures[:5])

mesures[:5] contient les cinq premières mesures : sa longueur vaut 5.

À retenir — les tirages au hasard

  • np.random.normal(10.00, 0.02, 1000) : un tableau de 1000 valeurs tirées au hasard selon une loi normale (en cloche), de moyenne 10,00 et d'écart-type 0,02. On l'utilise quand on connaît l'incertitude-type d'une grandeur.
  • np.random.uniform(9.98, 10.02, 1000) : 1000 valeurs tirées au hasard selon une loi uniforme, entre 9,98 et 10,02, toutes les valeurs de l'intervalle ayant la même chance. On l'utilise pour une tolérance « ± » de fabricant.
  • Chaque exécution tire de nouvelles valeurs : les résultats changent légèrement.

3.2 Une pipette jaugée, au hasard

Le fabricant d'une pipette jaugée de 10 mL garantit un volume de (10,00 ± 0,02) mL. On simule 10 000 volumes délivrés de deux façons : par une loi normale d'écart-type 0,02 mL, puis par une loi uniforme entre 9,98 et 10,02 mL.

  1. Compléter la ligne V_uniforme = ……, puis exécuter.
  2. Exécuter de nouveau : qu'est-ce qui change ? qu'est-ce qui reste ?
  3. Comparer la forme des deux histogrammes et les deux écarts-types.
  1. La ligne ressemble à celle de V_normale, avec np.random.uniform.
  2. np.random.uniform attend les deux bornes de l'intervalle, puis le nombre de tirages N.
Voir une solution

À chaque exécution, les moyennes et les écarts-types changent dans le 4ᵉ chiffre après la virgule, mais restent proches : 10,00 mL ; 0,020 mL pour la loi normale, 0,012 mL pour la loi uniforme. L'histogramme normal est en cloche et déborde un peu de l'intervalle ± 0,02 ; l'uniforme est plat, sans aucune valeur au-delà des bornes.

Derrière le rideau

L'écart-type d'une loi uniforme de demi-largeur a vaut a / √3 : ici 0,02 / √3 ≈ 0,012 mL. C'est pourquoi certains sujets divisent une tolérance par √3 pour obtenir une incertitude-type. Quant au « hasard » de l'ordinateur, il n'en est pas un : c'est une suite de calculs si embrouillée que ses résultats ont l'air imprévisibles. Les physiciens l'appellent pseudo-aléatoire, et s'en servent depuis les années 1940 : la méthode de Monte-Carlo, du nom du célèbre casino, est née pendant la mise au point des premiers ordinateurs.

Projet 1 — Superposer deux signaux synchrones

Deux haut-parleurs, branchés sur le même générateur, émettent des sons de même fréquence : ils sont synchrones. Un microphone placé devant eux reçoit la somme des deux signaux. Selon le décalage entre les deux, cette somme est forte, faible ou nulle : ce sont les interférences.

Au programme de terminale

Capacité numérique : « Représenter, à l'aide d'un langage de programmation, la somme de deux signaux sinusoïdaux périodiques synchrones en faisant varier la phase à l'origine de l'un des deux. »

À retenir

  • np.sin(x) calcule le sinus de x, en radians ; π rad correspondent à 180°.
  • Un signal sinusoïdal d'amplitude A, de fréquence f et de phase à l'origine φ s'écrit A * np.sin(2 * np.pi * f * t + phi).
  • np.max(u) donne la plus grande valeur du tableau u : pour un signal sinusoïdal, son amplitude.
Rappel de cours — Interférences et déphasage

Deux ondes de même nature, synchrones (même fréquence) et cohérentes interfèrent : la perturbation résultante est la somme des deux perturbations.

Déphasage

0 rad : ondes en phase, la somme a une amplitude maximale, interférences constructives.
π rad : ondes en opposition de phase, la somme est minimale, nulle si les deux amplitudes sont égales : interférences destructives.

4.1 En phase, en opposition

Les deux signaux ont la même amplitude A = 1,0 V et la même fréquence f = 440 Hz. Le second est déphasé de φ par rapport au premier.

  1. Compléter les lignes u2 = …… et u = ……, puis exécuter avec φ = 0. Relever l'amplitude de la somme.
  2. Remplacer phi = 0 par phi = np.pi. Exécuter et décrire la somme.
  3. Essayer phi = np.pi / 2. L'amplitude est-elle maximale, nulle, ou entre les deux ?
  4. Relier les questions 1 et 2 aux interférences constructives et destructives.
  1. u2 s'écrit comme u1, avec + phi à l'intérieur du sinus.
  2. La superposition est la somme des deux signaux : u1 + u2.
Voir une solution 
u2 = A * np.sin(2 * np.pi * f * t + phi)
u = u1 + u2

Pour φ = 0, les deux signaux sont confondus et la somme atteint 2,0 V : interférences constructives. Pour φ = π, les crêtes de l'un tombent sur les creux de l'autre : la somme est nulle à chaque instant, interférences destructives. Pour φ = π/2, l'amplitude vaut 1,41 V : un cas intermédiaire. Dans tous les cas, la somme reste un signal sinusoïdal de même fréquence, 440 Hz.

  3. Compléter la seconde condition, pour signaler les déphasages où elles sont constructives (amplitude supérieure à 1,99 V).

  2. Une fois ajoutée, cette amplitude est aussi le dernier élément de la liste : amplitudes[-1].

L'amplitude vaut 2,0 V pour φ = 0 et φ = 2π (les signaux sont en phase), et 0 pour φ = π (opposition de phase). Entre les deux, elle varie continûment. Déphaser de 2π revient à décaler d'une période entière : les deux signaux sont de nouveau en phase. Projet 2 — La longueur d'onde d'un laser, par diffraction

Comme au TP1, un laser éclaire des fentes de largeurs différentes, et l'on mesure la largeur de la tache centrale sur un écran. C'est le chapitre le plus présent dans les sujets d'ECE avec Python : on y teste un modèle, puis on en tire la longueur d'onde et son incertitude.

TP1 — Diffraction de la lumière
Rappel de cours — Diffraction par une fente

Pour une fente de largeur a éclairée en lumière de longueur d'onde λ, l'angle caractéristique θ vérifie, pour de petits angles :

θ ≈ λa θ ≈ L2D

On en déduit la largeur de la tache centrale : L = 2λD × 1a. L est donc proportionnelle à 1/a, avec un coefficient k = 2λD. Toutes les longueurs en mètres.

D'après ECE PC, banque 2026, sujets n° 52, 59, 78 et 89 : saisir les largeurs a et L mesurées, convertir les unités, choisir la grandeur portée en abscisse, puis lire la longueur d'onde et son incertitude.

5.1 Quel modèle ?

Mesures du TP1 : λ = 650 nm, D = 1,50 m. Le programme trace L en fonction d'une grandeur x à choisir, avec la droite passant par l'origine la plus proche des points ; son coefficient directeur k est calculé par une ligne fournie, comme dans les sujets 59 et 89.

  4. Revenir à x = 1/a. Ajouter une ligne qui calcule la longueur d'onde lam à partir de k et de D, et l'afficher en nm.
  1. 1 µm = 10⁻⁶ m et 1 cm = 10⁻² m : on multiplie par 1e-6 et par 1e-2.
  2. a² s'écrit a ** 2, et 1/a² s'écrit 1 / a ** 2 : la puissance passe avant la division.

%AH = 1001 + 10pH − pKA %A⁻ = 100 − %AH

À l'intersection des deux courbes, les deux pourcentages valent 50 % : pH = pKA.

6.2 Le taux d'avancement final

Rappel de cours — Taux d'avancement final

Le taux d'avancement final vaut τ = xfxmax. Pour un acide fort, τ = 1 ; pour un acide faible, τ < 1.

Pour un acide AH de concentration apportée C, on note x la concentration finale en ions oxonium. Le tableau d'avancement donne [A⁻] = [H3O+] = x et [AH] = C − x, donc :

KA = [A⁻] × [H3O+][AH] = x²C − x et τ = xC

L'équation à résoudre

x est solution de l'équation du second degré x² + KAx − KAC = 0, de la forme ax² + bx + c = 0 avec a = 1, b = KA et c = −KAC. Son discriminant vaut Δ = b² − 4ac, et sa seule racine positive :

x = −b + √Δ2a

On dissout de l'acide éthanoïque dans l'eau : C = 1,0 × 10⁻² mol·L⁻¹, pKA = 4,8.

  1. Compléter les lignes delta, x et tau, puis exécuter.
  2. L'acide éthanoïque est-il un acide fort ou faible ? Vérifier la valeur de τ avec la relation τ = 10−pH / C.
  1. Avec a = 1, b = KA et c = −KAC : Δ = KA² + 4 KAC, soit Ka ** 2 + 4 * Ka * C.
  2. La racine positive : (-Ka + np.sqrt(delta)) / 2.
  3. τ est le rapport de x à C.
Voir une solution 
delta = Ka ** 2 + 4 * Ka * C
x = (-Ka + np.sqrt(delta)) / 2
tau = x / C

Python affiche [H3O+] ≈ 3,9 × 10⁻⁴ mol·L⁻¹, pH = 3,41 et τ = 3,9 % : moins de 4 molécules d'acide sur 100 ont réagi avec l'eau. τ < 1 : l'acide éthanoïque est un acide faible. Vérification : 10−3,41 / 0,010 ≈ 0,039. Sans Python, on résoudrait la même équation à la calculatrice ; le programme, lui, se réutilise pour n'importe quelle concentration.

6.3 Diluer l'acide

On reprend le calcul de l'exercice 6.2 pour quatre concentrations, de 10⁻¹ à 10⁻⁴ mol·L⁻¹.

  1. Compléter les trois lignes de la boucle, en recopiant celles de l'exercice 6.2, puis exécuter.
  2. Comment évolue le taux d'avancement final quand on dilue l'acide ?
  1. Les trois lignes sont identiques à celles de 6.2 : à chaque tour, C prend une nouvelle valeur, et les calculs suivent.
  2. Elles doivent rester décalées de quatre espaces, pour faire partie de la boucle.
Voir une solution 
for C in concentrations:
    delta = Ka ** 2 + 4 * Ka * C
    x = (-Ka + np.sqrt(delta)) / 2
    tau = x / C
    print('C =', C, 'mol/L   τ =', round(tau * 100, 1), '%')

τ vaut 1,3 % ; 3,9 % ; 11,8 % puis 32,7 %. Plus on dilue, plus la réaction de l'acide faible avec l'eau avance, sans jamais être totale. La force d'un acide se compare donc à concentrations égales.

Projet 4 — Incertitudes : mesurer plus, ou simuler

Deux façons d'évaluer une incertitude avec Python. Quand on peut répéter la mesure : l'incertitude de type A, qui diminue avec le nombre de mesures. Quand le résultat se calcule à partir de plusieurs grandeurs mesurées : la simulation de Monte-Carlo.

Au programme de terminale

« Représenter l'histogramme associé à une série de mesures à l'aide d'un tableur ou d'un langage de programmation. » — « Simuler, à l'aide d'un langage de programmation, un processus aléatoire illustrant la détermination de la valeur d'une grandeur avec incertitudes-types composées. »

7.1 Combien de mesures faut-il ?

Rappel de cours — Incertitude de type A

u(x̄) = s(x)√n

L'incertitude-type de la moyenne s'écrit avec un seul chiffre significatif, arrondi à l'excès ; la moyenne est arrondie au même rang.

On reprend les vingt mesures du pH de l'eau du robinet (exercice 3.1). La première partie du programme trace l'histogramme et calcule le résultat. La seconde calcule l'incertitude-type en ne gardant que les 5, 10, 15 puis 20 premières mesures.

  1. Exécuter. Écrire le résultat de la mesure du pH.
  2. Compléter les deux lignes de la boucle, puis exécuter de nouveau.
  3. Comment l'incertitude évolue-t-elle avec le nombre de mesures ? Combien de fois plus de mesures faut-il, environ, pour la diviser par deux ?
  1. Les n premières mesures forment la tranche mesures[:n].
  2. Leur incertitude-type : np.std(serie, ddof=1) / np.sqrt(n).
Voir une solution 
for n in nombres:
    serie = mesures[:n]
    incertitudes.append(np.std(serie, ddof=1) / np.sqrt(n))

Avec les vingt mesures : moyenne 7,618, u = 0,0093, d'où pH = 7,62 ± 0,01. L'histogramme montre les mesures regroupées autour de 7,62. L'incertitude passe de 0,023 (5 mesures) à 0,014, 0,011 puis 0,009 (20 mesures) : quatre fois plus de mesures la divisent par 2 environ, comme le prévoit le √n de la formule. Mesurer plus améliore la précision, mais de moins en moins vite.

7.2 Monte-Carlo : les fentes de Young

Rappel de cours — Composer des incertitudes

Pour une grandeur obtenue par produit ou quotient, λ = i × bD, on compose les incertitudes relatives :

u(λ) = λ × √(u(i)i)² + (u(b)b)² + (u(D)D)²

Méthode de Monte-Carlo

On tire au hasard des valeurs possibles de chaque grandeur, selon son incertitude ; on recalcule le résultat un grand nombre de fois ; l'écart-type des résultats obtenus est l'incertitude-type du résultat.

Application de la fiche de cours : avec des fentes de Young distantes de b = 0,50 mm (u = 0,01 mm), à D = 1,00 m de l'écran (u = 0,01 m), on mesure l'interfrange i = 2,20 mm (u = 0,05 mm). On calcule λ = i × b / D et son incertitude, de deux façons.

  1. Compléter les lignes b_sim, D_sim et lam_sim, puis exécuter. Décrire l'histogramme.
  2. Exécuter plusieurs fois. L'incertitude obtenue change-t-elle beaucoup ?
  3. Compléter la ligne u_formule avec la formule du rappel, et comparer les deux incertitudes. Écrire le résultat.
  1. b_sim et D_sim s'écrivent comme i_sim : loi normale, centrée sur la valeur mesurée, d'écart-type son incertitude-type.
  2. lam_sim se calcule comme λ, avec les tableaux simulés.
  3. La formule : lam * np.sqrt((u_i / i) ** 2 + (u_b / b) ** 2 + (u_D / D) ** 2).
Voir une solution 
b_sim = np.random.normal(b, u_b, N)
D_sim = np.random.normal(D, u_D, N)
lam_sim = i_sim * b_sim / D_sim
...
u_formule = lam * np.sqrt((u_i / i) ** 2 + (u_b / b) ** 2 + (u_D / D) ** 2)

L'histogramme des 100 000 valeurs simulées est en cloche, centré sur λ = 1,10 × 10⁻⁶ m. D'une exécution à l'autre, u(λ) ne change que dans le troisième chiffre : 3,5 × 10⁻⁸ m, la valeur que donne la formule. On écrit λ = (1,10 ± 0,04) µm. La simulation n'a demandé aucune formule d'incertitude : c'est son intérêt quand la relation devient compliquée.

Bon à savoir

Projet 5 — La vitesse d'une voiture, par effet Doppler

Au TP5, une petite voiture portant un émetteur d'ultrasons de 40 000 Hz roule vers un récepteur. Le décalage Doppler a été mesuré plusieurs fois à deux endroits du parcours, en changeant le seuil de déclenchement de l'acquisition : 150 mV, puis 250 mV. La voiture a-t-elle la même vitesse aux deux endroits ?

TP5 — Ondes sonores et effet Doppler
Rappel de cours — Effet Doppler et incertitudes

Pour un émetteur qui s'approche d'un récepteur à une vitesse v faible devant c :

Δf ≈ fE × vc donc v = c × ΔffE et u(v) = c × u(Δf)fE

Comparer deux mesures

La différence v1 − v2 a pour incertitude-type √(u(v1)² + u(v2)²). On la compare à 0 par un z-score :

z = |v1 − v2|√(u(v1)² + u(v2)²)

Si z < 2, les deux vitesses sont compatibles ; sinon, elles diffèrent.

Projet 6 — Le sérum physiologique, par conductimétrie

Au TP4, on a dosé le chlorure de sodium d'un sérum physiologique par étalonnage. Ce projet reprend toute la chaîne de l'exploitation : droite d'étalonnage, concentration du sérum dilué, dilution, concentration en masse, incertitude et comparaison à l'étiquette, qui annonce 9,0 g·L⁻¹.

Rappel de cours — Dosage par étalonnage

Loi de Kohlrausch

Pour une solution diluée d'un seul soluté ionique, σ = k × c : une concentration inconnue se calcule par c = σk.

Dilution et concentration en masse

Une solution diluée F fois est F fois moins concentrée : cmère = F × cfille. La concentration en masse vaut t = c × M, avec c en mol·L⁻¹ et M en g·mol⁻¹.

Le jour de l'épreuve

Vous avez mené six situations d'ECE complètes. Cette dernière étape rassemble la méthode, et un dernier outil : savoir lire un affichage que vous n'aurez pas écrit.

Le jour de l'épreuve, Python n'occupe qu'une partie du sujet. Le programme est fourni, presque entièrement écrit et commenté : on ne vous demande jamais d'écrire un programme entier.

Vous aurez à saisir vos mesures dans une liste ou un np.array, et parfois à compléter une formule, une conversion d'unités, un titre ou le nom d'un axe.

Il faut ensuite exécuter, puis exploiter : lire une valeur, comparer des mesures à un modèle, écrire un résultat avec son incertitude, conclure à l'aide d'un z-score.

Les fonctions utiles sont rappelées dans le sujet : rien n'est à connaître par cœur. Il faut en revanche savoir lire un programme : repérer ce qui est à compléter, et comprendre ce que calcule chaque ligne.

À retenir — la méthode

  1. Lire tout le programme avant de toucher à quoi que ce soit : repérer les lignes à compléter et les unités notées en commentaire.

  3. Exécuter tout de suite, et lire le message d'erreur s'il y en a un : la ligne, puis le type d'erreur.
  4. Critiquer le résultat : ordre de grandeur, unité. Python ne signale jamais un résultat absurde.
  5. Exploiter par écrit : le résultat avec son incertitude et ses chiffres significatifs, puis une conclusion justifiée.

À retenir — lire un affichage formaté

  • Plusieurs sujets affichent leurs résultats avec f"…" : dans ce texte, chaque {…} est remplacé par sa valeur.
  • {x:.2f} affiche x avec 2 chiffres après la virgule ; {x:.0f}, arrondi à l'unité ; {x:.1e}, en écriture scientifique avec 1 chiffre après la virgule.

Pour chaque situation, choisir la bonne réponse. Les questions sur Python se vérifient dans l'éditeur.

Le bon réflexe

Le sujet indique a = np.array([ , , , , ]) # en µm. Vous avez mesuré 50, 100, 200, 280 et 400 µm. Quelle saisie est correcte ?

Des crochets, et une virgule entre deux valeurs. Sans crochets, np.array reçoit cinq nombres au lieu d'une liste : erreur. La dernière proposition a oublié la mesure de 280 µm : la liste n'aurait plus la même longueur que celle des L.

Il faut convertir ces largeurs en mètres. Quelle ligne convient ?

1 µm = 10⁻⁶ m, qui s'écrit 1e-6. 10e-6 vaut 10⁻⁵, dix fois trop ; ^ n'est pas une puissance ; diviser par 1e-6 revient à multiplier par un million.

Que vaut f"u = {u:.1e} m", avec u = 2.948e-9 ?

.1e : écriture scientifique, un chiffre après la virgule. 2,948 s'arrondit à 2,9. Python écrit toujours l'exposant avec deux chiffres : e-09.

Le programme affiche λ moyenne = 652.9 nm u = 2.9 nm. Comment écrire le résultat ?

L'incertitude s'écrit avec un chiffre significatif, arrondi à l'excès : 2,9 devient 3 nm. La valeur est arrondie au même rang, l'unité : 653 nm.

Le programme affiche z = 2.4. Quelle conclusion écrire ?

z ≥ 2 : l'écart vaut plus de deux fois l'incertitude, les valeurs ne sont pas compatibles. On cherche alors une cause : erreur de mesure, incertitude sous-estimée, modèle qui ne convient pas.
