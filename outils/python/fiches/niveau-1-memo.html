Exemple commenté 1 · une courbe d'étalonnage, comme à l'ECE

import numpy as np                       # 1. charger les bibliothèques, toujours en premier
import matplotlib.pyplot as plt

# 2. saisir les mesures : listes entre crochets, POINT décimal, même longueur
c = np.array([1.0, 2.5, 5.0, 8.0, 10.0])               # en mmol/L
sigma = np.array([0.162, 0.330, 0.605, 0.925, 1.158])  # en mS/cm

# 3. le modèle : on calcule sur 100 valeurs d'un coup (tableau numpy)
k = 0.1172
c_mod = np.linspace(0, 11, 100)        # 100 concentrations de 0 à 11
sigma_mod = k * c_mod                   # loi de Kohlrausch, sur les 100 valeurs

# 4. exploiter : une concentration inconnue, affichée avec son unité
c_serum = 0.869 / k
print('c du sérum =', round(c_serum, 2), 'mmol/L')

# 5. tracer : mesures en points, modèle en ligne, axes TOUJOURS légendés
plt.plot(c, sigma, 'b+', label='mesures')
plt.plot(c_mod, sigma_mod, 'r-', label='modèle')    # c_mod avec sigma_mod : même longueur
plt.xlabel('c (mmol/L)')
plt.ylabel('σ (mS/cm)')
plt.legend()
plt.show()                              # 6. afficher, en dernier

c du sérum = 7.41 mmol/L

Exemple commenté 2 · une série de mesures et son incertitude

import numpy as np
import matplotlib.pyplot as plt

# 15 pesées du même cylindre d'aluminium, en g ; la liste continue sur deux lignes
m = np.array([55.47, 55.43, 55.45, 55.44, 55.48, 55.42, 55.46, 55.45,
              55.43, 55.47, 55.44, 55.46, 55.42, 55.45, 55.46])

n = len(m)                       # nombre de mesures : 15
m_moy = np.mean(m)               # moyenne : meilleure estimation de la masse
s = np.std(m, ddof=1)            # écart-type EXPÉRIMENTAL (divise par n - 1) : ddof=1 obligatoire
u = s / np.sqrt(n)               # incertitude-type de la moyenne (type A)

print('n =', n)
print('moyenne =', round(m_moy, 3), 'g')
print('u =', round(u, 4), 'g')    # on écrira u à 1 chiffre significatif, arrondi à l'excès

plt.hist(m, bins=5, edgecolor='black')    # répartition des mesures en 5 classes
plt.xlabel('masse (g)')
plt.ylabel('effectif')
plt.show()

n = 15 moyenne = 55.449 g u = 0.0048 g

Résultat : m = (55,449 ± 0,005) g. L'histogramme montre les mesures regroupées autour de la moyenne.

Exemple commenté 3 · des variables, numpy et un affichage soigné

import numpy as np

# effet Doppler : émetteur de 40 kHz qui s'approche à 2,0 m/s
f_E = 40000                     # Hz ; pas d'espace dans un nombre
v = 2.0                         # m/s
c = 340                         # m/s
lam = c / f_E                   # « lambda » est un mot réservé : on écrit lam

f_R = f_E * c / (c - v)         # expression exacte ; les parenthèses fixent l'ordre
delta_f = f_R - f_E
delta_f_approx = f_E * v / c    # expression approchée (v faible devant c)

print('lambda =', lam, 'm')              # dans un texte, « lambda » est permis
print('Δf exact =', round(delta_f, 1), 'Hz')
print('Δf approché =', round(delta_f_approx, 1), 'Hz')
print('L =', 10 * np.log10(1.0e-5 / 1.0e-12), 'dB')   # log10, pas log

lambda = 0.0085 m Δf exact = 236.7 Hz Δf approché = 235.3 Hz L = 70.0 dB

Lire un message d'erreur

Regarder la dernière ligne (le type d'erreur) et le numéro de ligne. Si la ligne paraît juste, remonter d'une ligne.

SyntaxErrorla ligne n'est pas du Python : parenthèse ou guillemet non fermé, virgule décimale, mot réservé
NameErrornom inconnu : majuscule, faute de frappe, variable pas encore définie, texte sans guillemets
TypeErroropération impossible : texte + nombre, calcul sur une liste au lieu d'un np.array
IndexErrorélément qui n'existe pas : x[5] dans une liste de 5 valeurs
ValueErrordans plt.plot : x and y must have same first dimension, listes de longueurs différentes
aucun messagerésultat faux : vérifier l'ordre de grandeur, les unités, log ou log10, ^ ou **

Ce que je sais faire

  • Calculer dans la console, avec le point décimal et la notation e.
  • Ranger des valeurs dans des variables, sans mot réservé.
  • Distinguer nombre et texte ; afficher valeur arrondie et unité.
  • Utiliser np.log10 et np.sqrt, sans confondre avec np.log.
  • Saisir des mesures dans une liste et calculer sur tout le tableau.
  • Calculer moyenne, écart-type et incertitude-type.
  • Tracer points, modèle et histogramme, axes légendés.
  • Lire un message d'erreur ; douter d'un résultat aberrant.
