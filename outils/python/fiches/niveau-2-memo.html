  6. Exploiter par écrit : incertitude à 1 chiffre significatif, arrondie à l'excès ; valeur au même rang ; conclusion justifiée.

Exemple commenté 1 · type A, z-score et conclusion (d'après les sujets 78 et 89)

import numpy as np

# 1. les mesures : listes de même longueur, point décimal, unités en commentaire
D = 1.50                                                       # en m
a = np.array([40, 50, 70, 100, 120, 280, 400]) * 1e-6          # µm -> m
L = np.array([4.9, 3.9, 2.8, 2.0, 1.6, 0.70, 0.49]) * 1e-2     # cm -> m
lam_ref = 650e-9                                            # valeur de référence

# 2. un λ par fente, d'un coup : L = 2λD/a donne λ = L·a/(2D) ; parenthèses obligatoires
lam = L * a / (2 * D)

# 3. incertitude de type A : écart-type expérimental (ddof=1), divisé par racine de n
n = len(lam)
lam_moy = np.mean(lam)
u_lam = np.std(lam, ddof=1) / np.sqrt(n)
print('λ =', round(lam_moy * 1e9, 1), 'nm   u =', round(u_lam * 1e9, 1), 'nm')

# 4. z-score, puis conclusion : un seul bloc est exécuté, le premier dont la condition est vraie
z = abs(lam_moy - lam_ref) / u_lam
print('z =', round(z, 2))
if z < 1:                                # deux-points, puis bloc décalé de 4 espaces
    print('valeurs très compatibles')
elif z < 2:                              # testé seulement si z >= 1
    print('valeurs compatibles')
else:
    print('valeurs non compatibles')

λ = 652.9 nm u = 2.9 nm z = 0.97 valeurs très compatibles

Résultat écrit : λ = (653 ± 3) nm. L'incertitude 2,9 nm est arrondie à l'excès, à un chiffre : 3 nm ; la valeur, au même rang.

Exemple commenté 2 · simulation de Monte-Carlo (d'après les sujets 1, 22 et 78)

import numpy as np

# fentes de Young : λ = i × b / D, chaque grandeur avec son incertitude-type
N = 100000                                         # nombre de tirages
i_sim = np.random.normal(2.20e-3, 0.05e-3, N)       # valeur, incertitude-type, N
b_sim = np.random.normal(0.50e-3, 0.01e-3, N)
D_sim = np.random.normal(1.00, 0.01, N)
# une tolérance « ± t » de fabricant se simule par np.random.uniform(x - t, x + t, N)

lam_sim = i_sim * b_sim / D_sim             # N valeurs possibles de λ, calculées d'un coup
print(f"λ = {np.mean(lam_sim):.2e} m")                   # .2e : 2 chiffres après la virgule
print(f"u(λ) = {np.std(lam_sim, ddof=1):.1e} m")        # l'écart-type des résultats = u(λ)

λ = 1.10e-06 m u(λ) = 3.5e-08 m

Les tirages changent à chaque exécution, mais le résultat reste stable à ce nombre de chiffres. La formule de composition des incertitudes relatives donne la même valeur : λ = (1,10 ± 0,04) µm.

Exemple commenté 3 · une boucle, une tranche, une liste construite

import numpy as np

# 20 mesures du pH de l'eau du robinet ; la liste continue sur deux lignes
mesures = np.array([7.62, 7.58, 7.65, 7.60, 7.71, 7.55, 7.63, 7.59, 7.66, 7.61,
                    7.57, 7.64, 7.68, 7.60, 7.62, 7.56, 7.67, 7.63, 7.59, 7.61])

incertitudes = []                     # liste vide, remplie au fil de la boucle
for n in [5, 10, 20]:                # n vaut 5, puis 10, puis 20
    serie = mesures[:n]               # tranche : les n premières mesures
    u = np.std(serie, ddof=1) / np.sqrt(n)
    incertitudes.append(u)            # ajout à la fin de la liste
    print(n, 'mesures : u =', round(u, 3))
print(incertitudes[-1] < incertitudes[0])   # hors de la boucle : une comparaison

5 mesures : u = 0.023 10 mesures : u = 0.014 20 mesures : u = 0.009 True

Quatre fois plus de mesures divisent l'incertitude par 2 environ : c'est le √n de la formule. Résultat : pH = 7,62 ± 0,01.
