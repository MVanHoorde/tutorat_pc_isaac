Exemple commenté 1 · du fichier de mesures au modèle

import numpy as np
import matplotlib.pyplot as plt

# 1. lire le fichier : séparateur ; et une ligne d'en-tête « t (s);y (m) » à sauter
t, y = np.loadtxt('chute.csv', delimiter=';', skiprows=1, unpack=True)

# 2. dériver : vitesse centrée, 2 valeurs de moins que les positions
vy = (y[2:] - y[:-2]) / (t[2:] - t[:-2])
tv = t[1:-1]                        # les dates des vitesses
print(len(t), 'positions,', len(vy), 'vitesses')

# 3. modéliser : droite vy = a × t + b ; les abscisses d'abord ; ici a ≈ -g et b ≈ 0
a, b = np.polyfit(tv, vy, 1)
print('a =', round(a, 2), 'm/s²   b =', round(b, 3), 'm/s')

# 4. tracer mesures et modèle, avec des tableaux de même longueur
plt.plot(tv, vy, 'b+', label='mesures')
plt.plot(tv, a * tv + b, 'r-', label='modèle')
plt.xlabel('t (s)')
plt.ylabel('vy (m/s)')
plt.legend()
plt.show()

14 positions, 12 vitesses a = -9.79 m/s² b = -0.005 m/s

Exemple commenté 2 · la méthode d'Euler, rangée dans une fonction

import numpy as np

def euler(a, b, y0, dt, n):        # résout y' = a × y + b, en n pas de durée dt
    y = y0                           # valeur initiale y(0)
    liste_y = [y]
    for i in range(n):
        y = y + (a * y + b) * dt     # un pas : y(t + dt) ≈ y(t) + y'(t) × dt
        liste_y.append(y)
    return liste_y                   # renvoyer, pas afficher : on calcule ensuite avec

# charge d'un condensateur : du/dt = (E - u) / tau, soit a = -1/tau et b = E/tau
E, tau = 12.0, 22.0                 # en V et en s
u = euler(-1 / tau, E / tau, 0, 1.0, 140)    # pas de 1 s, de 0 à 140 s
print(len(u), 'valeurs ; u(22 s) =', round(u[22], 2), 'V')    # pas de 1 s : u[22] est à t = 22 s
print('solution exacte :', round(E * (1 - np.exp(-1)), 2), 'V')

141 valeurs ; u(22 s) = 7.69 V solution exacte : 7.59 V

À la date τ, 63 % de E. L'écart avec la solution exacte diminue si l'on réduit le pas. La même fonction résout la décroissance radioactive : euler(-lam, 0, N0, dt, n).

Exemple commenté 3 · une dichotomie réutilisable

import numpy as np

def dichotomie(f, a, b, precision):   # f(a) et f(b) doivent être de signes contraires
    while b - a > precision:          # tant que l'encadrement est trop large
        m = (a + b) / 2
        if f(a) * f(m) <= 0:          # le changement de signe est dans [a ; m]
            b = m
        else:                         # sinon, il est dans [m ; b]
            a = m
    return (a + b) / 2

# acide éthanoïque à c = 1,0 × 10⁻² mol/L : x = [H3O+] vérifie x² + Ka x - Ka c = 0
c = 1.0e-2
Ka = 10 ** (-4.76)

def f(x):
    return x ** 2 + Ka * x - Ka * c

x = dichotomie(f, 0, c, 1e-9)       # le nom f, sans parenthèses : on donne la fonction
print('[H3O+] =', round(x, 6), 'mol/L')
print('tau =', round(x / c, 3), '; pH =', round(-np.log10(x), 2))

[H3O+] = 0.000408 mol/L tau = 0.041 ; pH = 3.39

Taux d'avancement final τ ≈ 4 % : la réaction de l'acide sur l'eau est très limitée. Chaque tour divise l'encadrement par deux : 24 tours ici, pour passer de 10⁻² à moins de 10⁻⁹.
