Séance 1 — Python, une calculatrice

Python calcule comme une calculatrice. Caractères à vérifier : é è à ç œ « guillemets » l’apostrophe – tiret, 3 × 10⁻¹ ≈ 0,3 ; m² ; m³ ; λ θ σ Δ μ ; 20 °C. Un mot-clé du cours, une variable c. Italique : la célérité c.

À retenir ★★

  • La puissance s'écrit ** : 10**3 vaut 1000.
  • La virgule décimale s'écrit avec un point : 2.25.
      c = 340          # célérité du son, en m/s
      d = c * 2.5
      print("distance :", d, "m")
    
      distance : 850.0 m

Bon à savoir

Le point décimal vient de la notation anglo-saxonne : 0.68 se lit « zéro point soixante-huit ».

Rappel de cours — Niveau d'intensité sonore

Définition

Le niveau d'intensité sonore L (en dB) d'un son d'intensité I (en W·m⁻²) est :

L = 10 × log(II0)

Valeurs de référence

Seuil d'audibilité : I0 = 1,0 × 10⁻¹² W·m⁻². Une période vaut 1f et λ ≈ cf.

θ ≈ λa et Δf = fE × vc ; σ = ε × ℓ − 2

S'entraîner

1.1 Une première affectation

On affecte la célérité du son à une variable.

  1. Complétez la ligne pour que c vaille 340.
  2. Exécutez.
  1. Les points de suspension … sont à remplacer par une valeur.
  2. La célérité du son dans l'air vaut environ 340 m/s.
  3. La ligne complète s'écrit c = 340.
Voir une solution 
        c = 340
        print("c =", c)

On remplace les points de suspension par la valeur.
